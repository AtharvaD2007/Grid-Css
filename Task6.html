1. What are grid lines?

Grid lines are invisible lines that divide the grid into rows and columns.

2. How many columns does the item span?

It spans the number of columns between the start and end grid lines.

3. What happens to other items?

Other grid items automatically adjust their position.

4. Can two items overlap?

Yes, but only if explicitly forced.

5. Where is column spanning used in websites?

Image banners and dashboards
