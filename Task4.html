1. What does auto do in grid rows?

Auto allows the row height to adjust automatically according to the content inside it.

2. Which row grows based on content?

The row that uses auto grows based on content.

3. Can rows have different heights?

Yes, grid rows can have different heights.

4. What happens if content is very large?

With auto the row expands to fit all the content. With fixed height content may overflow, scroll, or get hidden

5. Where are grid rows useful in real layouts?

Dashboards, Card layouts
