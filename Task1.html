1. What is the difference between a normal div and a grid container?

A normal div behaves like a block element and places its child elements one below another. A grid container uses CSS Grid rules and allows us to arrange its child elements in rows and columns.

2. Why does the layout look the same even after applying Grid?

By default, Grid places all items in a single column, which is the same way normal block elements behave. That is why there is no visible change.

3. Are grid items created automatically?

Yes.

4. Can Grid work without rows or columns?

Yes, Grid still works without defining rows or columns, but it will not show any visible layout change.

5. What do you think Grid needs to show visible changes?

Grid needs defined rows or columns (like grid-template-columns or grid-template-rows) to show visible changes.
