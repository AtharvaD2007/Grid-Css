1. Why do we check browser support?

To ensure the CSS feature works correctly in the user's browser.

2. What happens if Grid is not supported?

The browser ignores the Grid styles.

3. Is this needed for all projects?

Not always. Needed only if you must support older browsers or want progressive enhancement.

4. Who uses this in real projects?

Professional web developers and agencies

5. What does safe CSS mean?

CSS that does not break the layout even if some features are unsupported.
