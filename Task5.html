1. Where does gap add space?

gap adds space between grid items only.

2. How is gap different from margin?

gap adds space between grid items while margin adds space outside an element.

3. Does gap affect container size?

No.

4. Can we use gap only for rows or columns?

Yes.

5. Why is gap preferred in Grid layouts?

gap is preferred because it provides clean and uniform spacing and makes layouts easier to manage.
